# SAM Backend

The core engine that powers SAM-Frontend. A RESTful API built with Node.js, Express, TypeScript and MongoDB to manage Christian content dynamically.

> Provides authentication, content management, and media services for the SAM platform.

### Frontend Repo
- [SAM-Frontend](https://github.com/your-username/SAM-Frontend)

---

### Features

- **Content API** - CRUD for managed content, categories, pages
- **Admin Authentication** - JWT-based secure auth
- **Media Service** - Cloudinary integration for upload, listing, and safe deletion
- **Validation & Security** - Input validation, rate limiting, protected routes
- **Type-Safe** - Fully written in TypeScript

### Tech Stack

- **Runtime:** Node.js
- **Framework:** Express.js
- **Language:** TypeScript
- **Database:** MongoDB + Mongoose
- **Media Storage:** Cloudinary
- **Auth:** JWT + bcrypt
